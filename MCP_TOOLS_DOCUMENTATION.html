Documentação Completa - Ferramentas MCP de Vendas

Guia completo para utilizar as 12 ferramentas de análise de vendas disponíveis no servidor MCP. Inclui exemplos detalhados para Cline, Claude Desktop, Codex, Manus e outros clientes MCP.

Sobre este Sistema

O servidor MCP de Vendas fornece um conjunto abrangente de ferramentas para análise de dados de vendas, permitindo extrair insights valiosos sobre performance, tendências e oportunidades de negócio.

📊 12 Ferramentas

6 de análise geral + 6 de análise de vendedores

🔒 Autenticação JWT

Todas as ferramentas requerem autenticação

⚡ JSON-RPC 2.0

Protocolo padrão para comunicação MCP

Estrutura das Ferramentas

Todas as ferramentas seguem o mesmo padrão de implementação:

Nome da Ferramenta string

Identificador único no formato snake_case (ex: get_revenue_by_period)

Parâmetros object

Todos os parâmetros são validados e documentados com descrições claras

Retorno DTO específico

Estrutura tipada com todos os campos necessários para análise

Autenticação [Authorize] attribute

Todas as ferramentas requerem token JWT válido

Autenticação e Segurança

Todas as ferramentas requerem autenticação via JWT. Configure seu cliente MCP com o token apropriado.

Configuração do Token JWT

JSON 
// ~/Library/Application Support/Claude/claude_desktop_config.json
{
  "mcpServers": {
    "sales-analytics": {
      "command": "dotnet",
      "args": [
        "run",
        "--project",
        "d:/iaagentsautonomous/mcp-sales/Sales.Mcp.Server"
      ],
      "env": {
        "ASPNETCORE_ENVIRONMENT": "Development",
        "JWT_SECRET": "sua-chave-secreta-aqui"
      }
    }
  }
}
JSON 
// Configuração do Cline para usar as ferramentas MCP
// Use os comandos execute_command e access_mcp_resource

// Exemplo de como chamar uma ferramenta no Cline:
{
  "tool": "access_mcp_resource",
  "params": {
    "server_name": "sales-analytics",
    "uri": "tool://sales-analytics/get_revenue_by_period"
  }
}

// Ou usando execute_command para chamar via cURL:
{
  "tool": "execute_command",
  "params": {
    "command": "curl -X POST http://localhost:5000/mcp/tools/call \\\n  -H \"Authorization: Bearer SEU_TOKEN_JWT\" \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\"jsonrpc\":\"2.0\",\"method\":\"tools/call\",\"params\":{\"name\":\"get_revenue_by_period\",\"arguments\":{\"startDate\":\"2025-01-01\",\"endDate\":\"2025-12-31\",\"groupBy\":\"month\"}},\"id\":1}'",
    "requires_approval": false
  }
}
bash 
# Obter token JWT (exemplo)
curl -X POST http://localhost:5000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"senha-segura"}'

# Resposta esperada:
# {
#   "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
#   "expiresIn": 3600
# }

# Usar token nas requisições MCP
curl -X POST http://localhost:5000/mcp/tools/call \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "method": "tools/call",
    "params": {
      "name": "get_revenue_by_period",
      "arguments": {
        "startDate": "2025-01-01",
        "endDate": "2025-12-31",
        "groupBy": "month"
      }
    },
    "id": 1
  }'

⚠️ Importante: Ambiente de Desenvolvimento

Para desenvolvimento local, configure a variável de ambiente ASPNETCORE_ENVIRONMENT=Development para desabilitar algumas verificações de segurança.

🔐 Produção

Em produção, sempre use HTTPS, configure JWT_SECRET adequadamente e implemente rate limiting.

FAQ & Troubleshooting

Perguntas frequentes e soluções para problemas comuns ao usar as ferramentas MCP.

Problemas Comuns e Soluções

❌ Erro: "Authentication required"

Solução: Configure o token JWT no seu cliente MCP. Verifique a seção de Autenticação acima.

❌ Erro: "Invalid date format"

Solução: Use o formato yyyy-MM-dd para todas as datas (ex: 2025-01-01).

❌ Erro: "Tool not found"

Solução: Verifique se o servidor MCP está rodando e se o nome da ferramenta está correto.

❌ Erro: "Invalid parameter value"

Solução: Consulte a tabela de parâmetros para ver os valores permitidos para cada ferramenta.

Glossário

Definições de termos técnicos e de negócio utilizados nas ferramentas MCP.

Termos Técnicos

Termo Definição Exemplo
JSON-RPC Protocolo de chamada remota baseado em JSON Formato padrão para comunicação MCP
DTO Data Transfer Object - Objeto para transferência de dados Estrutura tipada de retorno das ferramentas
JWT JSON Web Token - Token de autenticação Usado para autenticar requisições MCP
MCP Model Context Protocol Protocolo para conectar LLMs a ferramentas externas

Termos de Negócio

Termo Definição Cálculo
Gross Revenue Faturamento bruto (antes de descontos/reembolsos) Soma de todos os valores de pedidos
Net Sales Vendas líquidas (após descontos) Gross Revenue - Descontos
Average Order Value Ticket médio Gross Revenue ÷ Order Count
Conversion Rate Taxa de conversão (Converted Orders ÷ Total Opportunities) × 100
Customer Retention Rate Taxa de retenção de clientes (Repeat Customers ÷ Total Customers) × 100
